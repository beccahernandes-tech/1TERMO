# 🎓 Grade Curricular e Repositório de Estudos

Este repositório centraliza os materiais teóricos, códigos práticos, diagramas e projetos desenvolvidos ao longo do curso. Abaixo está o resumo das disciplinas e competências abordadas.

---

## 🌐 1. Arquitetura IoT (Internet das Coisas)
Foco no design de sistemas embarcados e na comunicação de dados entre a borda (edge) e a nuvem.
*   **Conceitos:** Camadas da arquitetura IoT, protocolos de comunicação (MQTT, HTTP) e computação em névoa.
*   **Hardware:** Ecossistema Arduino, sensores, atuadores e módulos de conectividade (ESP32/ESP8266).
*   **Desenvolvimento:** Programação em C++ para o firmware dos dispositivos e Python para gateways e processamento em nuvem.

## 📋 2. Engenharia e Levantamento de Requisitos
Análise, modelagem e validação das necessidades de software e hardware de um projeto.
*   **Elicitação:** Técnicas de coleta de dados através de Brainstorms, Entrevistas e Prototipagem (baixa e alta fidelidade).
*   **Especificação:** Definição clara de Requisitos Funcionais (ações) e Não Funcionais (atributos de qualidade e segurança).
*   **Modelagem:** Construção de Diagramas UML (Casos de Uso, Atividades), BPMN e confecção de Relatórios Técnicos de engenharia.

## 🐍 3. Lógica de Programação
Construção do pensamento computacional e introdução ao controle de versão profissional.
*   **Lógica:** Algoritmos, variáveis, operadores, estruturas condicionais (`if/else`) e loops de repetição (`for/while`).
*   **Linguagem Python:** Desenvolvimento de scripts limpos, manipulação de funções e estruturas de dados básicas.
*   **Git & GitHub:** Versionamento local de código, fluxo de trabalho em equipe e publicação de portfólio via terminal.

## 💻 4. Sistemas Operacionais
Estudo comparativo dos conceitos estruturais, gerenciamento de recursos e arquiteturas de sistemas.
*   **Fundamentos:** Escalonamento de processos, gerenciamento de memória RAM/Virtual e sistemas de arquivos.
*   **Microsoft Windows:** Arquitetura de kernel híbrido (NT), padrão NTFS e o ecossistema WSL.
*   **Linux:** Kernel monolítico modular, sistema EXT4, permissões de segurança e operação via CLI (Bash).
*   **Apple iOS:** Kernel XNU (Unix), sistema de arquivos APFS e mecanismos rígidos de Sandbox para dispositivos móveis.
